# 2. 首页 `/`

首页是网站最重要的视觉入口。

核心原则：

> 打开网站后首先看到的是地球，而不是传统信息流。

桌面布局建议：

```text
┌──────────────────────────────────────────────┐
│ Logo       Search                +投稿  Login│
│                                              │
│                                              │
│               INTERACTIVE                    │
│                  EARTH                       │
│                                              │
│         ●               ●                    │
│                                              │
│                                              │
│  时间轴 ───────────────────── 2026           │
│                                              │
│  音乐剧  戏剧  综艺  晚会  音乐会 ...       │
└──────────────────────────────────────────────┘
```

---

# 3. 地球视觉层

地球默认包括：

* 深蓝海洋；
* 绿色 / 土黄色陆地；
* 白 / 浅蓝极地区域；
* 经纬网；
* 大气蓝色边缘光；
* 星空背景；
* 当前太阳照明；
* 昼夜分界；
* 夜侧城市灯光；
* 活动节点动态脉冲。

视觉上地球应该是首页绝对主体。

UI 不应该覆盖太多面积。

# 5. 地球旋转

支持：

```text
拖动
→ 旋转

滚轮
→ 缩放

双击区域
→ 放大

点击聚合节点
→ 自动飞近
```

用户停止操作数秒后可以恢复非常缓慢的自动旋转。

如果用户主动关闭：

```text
自动旋转
```

则保持静止。

# 7. 聚合节点

聚合节点：

```text
  37
```

表示当前位置附近有 37 个结果。

Hover：

```text
上海
37 场活动
```

点击：

```text
地图平滑放大
↓
37
↓
12 / 8 / 6 / ...
↓
最终展开单个 Event
```

动画约：

```text
300–600 ms
```

避免突然跳转。

# 8. 单活动节点

例如：

```text

```

# 45. MVP 的“完成标准”

第一版 MVP 不要求功能特别多。

只要能够完整跑通：

```text
打开网站

↓
看到地球

↓
旋转 / 放大

↓
进入中国

↓
进入北京

↓
看到剧院节点

↓
点击某场活动

↓
进入 Event 页面

↓
查看资料

↓
登录

↓
标记我参加过

↓
发现缺失活动

↓
提交活动

↓
管理员审核

↓
新节点出现在地图
```

这条链路真正跑通，就已经是一套完整产品，而不是 Demo。
